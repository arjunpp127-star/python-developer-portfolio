Student Marks Manager

Project Overview

A Python application for managing student marks, calculating grades, and ranking students.

Features

- Add student details
- Calculate grades automatically
- Display student records
- Rank students based on marks
- Save student data in CSV format

Technologies Used

- Python 3
- CSV module
- File handling
- Functions
- Sorting

Installation

1. Install Python 3.
2. Download or clone this repository.
3. Open the project folder in a terminal.
4. Run:

python student_marks_manager.py
